# Nathan Ewing site

Five plain HTML pages and one stylesheet. No build step, no installs.

## Open it
Double-click `index.html`. It opens in your browser. The menu links between pages.
(Fonts load from Google Fonts when online; offline the site falls back to Arial/system fonts.)

## Fill in the placeholders
Search the folder for `[PLACEHOLDER]` to find everything still to do:
- Home, About, Projects: your own writing
- Photo: save `photo.jpg` or `photo.png` in this folder, then swap the image tag on `index.html`
- Résumé: save `resume.pdf` in this folder, then link it on `resume.html`
- LinkedIn: add the link on `contact.html`
- Projects: report, slides and charts links

## Publish on GitHub Pages
Upload the *contents* of this folder (so `index.html` is at the top of the repo), then
Settings > Pages > Deploy from a branch > main / (root).

## Privacy
No phone number, home address, student ID, grades or transcript is on this site, by design.
